# Thư mục dành cho Team Cộng sự (Ring 3 - User App)

Thư mục này được sử dụng để phát triển ứng dụng Client (Giao diện người dùng, trình duyệt thi Webview2, AI, kết nối mạng) hoạt động ở chế độ User Mode (Ring 3).

**Lưu ý:**
- Ứng dụng này sẽ sử dụng file `../../include/SharedDef.h` để có thể giao tiếp đồng bộ với Driver thông qua các IOCTL.
- Code ở đây có thể là C++/Qt hoặc C# tùy theo quyết định của team Cộng sự.
